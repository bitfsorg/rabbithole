# 模块规范：internal/tx

## 目的

用于 BitFS Metanet 操作的 BSV 交易构建模块。构建所有文件系统操作所使用的四种交易模板（CreateRoot、CreateChild、SelfUpdate、DataTransaction）。管理自维持链的 UTXO 追踪，其中 Output[2] 刷新父节点 UTXO。

设计参考：ConceptDesign #8, #14, #24, #60; SystemDesign 第 4 节; DetailedDesign 第 4-B 节。

## 公共 API

### 常量

```go
const (
    MetaFlag       = "meta"          // 0x6d657461, 4 bytes ASCII
    MetaFlagBytes  = []byte{0x6d, 0x65, 0x74, 0x61}
    DustLimit      = uint64(546)     // Minimum P2PKH output in satoshis
    DefaultFeeRate = uint64(1)       // sat/KB default fee rate
)
```

### 类型

```go
// UTXO represents an unspent transaction output tracked by the wallet.
type UTXO struct {
    TxID         []byte `json:"txid"`          // 32 bytes
    Vout         uint32 `json:"vout"`
    Amount       uint64 `json:"amount"`        // satoshis
    ScriptPubKey []byte `json:"script_pubkey"` // locking script
    PrivateKey   *ec.PrivateKey `json:"-"`     // signing key (not serialized)
}

// MetanetTx wraps a built BSV transaction with metadata about produced UTXOs.
type MetanetTx struct {
    Tx           *transaction.Transaction // go-sdk Transaction
    NodeUTXO     *UTXO                   // Output 1: P_node UTXO (always present)
    ParentUTXO   *UTXO                   // Output 2: P_parent refresh UTXO (nil for root/self-update)
    ChangeUTXO   *UTXO                   // Last output: change (may be nil if dust)
}

// CreateRootParams holds parameters for building a root node transaction.
type CreateRootParams struct {
    NodePubKey  *ec.PublicKey   // P_node for the root
    NodePrivKey *ec.PrivateKey  // D_node (not used in tx, but for UTXO tracking)
    Payload     []byte          // Protobuf-encoded BitFSPayload
    FeeUTXO     *UTXO          // Fee chain UTXO to spend
    ChangeAddr  []byte          // 20-byte P2PKH hash for change
    FeeRate     uint64          // sat/KB (0 = use DefaultFeeRate)
}

// CreateChildParams holds parameters for building a child node transaction.
type CreateChildParams struct {
    NodePubKey    *ec.PublicKey
    ParentTxID    []byte          // 32 bytes, parent's latest TxID
    Payload       []byte          // Protobuf-encoded BitFSPayload
    ParentUTXO    *UTXO          // P_parent UTXO to spend (creates Metanet edge)
    ParentPrivKey *ec.PrivateKey  // D_parent for signing Input 0
    FeeUTXO       *UTXO
    ParentPubKey  *ec.PublicKey   // P_parent for Output 2 refresh
    ChangeAddr    []byte
    FeeRate       uint64
}

// SelfUpdateParams holds parameters for building a self-update transaction.
type SelfUpdateParams struct {
    NodePubKey   *ec.PublicKey
    NodePrivKey  *ec.PrivateKey  // D_node for signing Input 0
    ParentTxID   []byte          // Original parent TxID (preserved across updates)
    Payload      []byte          // Updated Protobuf payload
    NodeUTXO     *UTXO          // P_node's current UTXO to spend
    FeeUTXO      *UTXO
    ChangeAddr   []byte
    FeeRate      uint64
}

// DataTxParams holds parameters for building an on-chain data transaction.
type DataTxParams struct {
    NodePubKey    *ec.PublicKey
    NodePrivKey   *ec.PrivateKey  // D_node for OP_DROP output locking
    Content       []byte          // Encrypted content to embed
    SourceUTXO    *UTXO          // UTXO to spend
    ChangeAddr    []byte
    FeeRate       uint64
}
```

### 函数

```go
// BuildCreateRoot constructs a Metanet root node transaction.
// Template 1: No parent, creates initial P_node UTXO.
//
// Outputs:
//   0: OP_FALSE OP_RETURN <MetaFlag> <P_node> <empty> <Payload>
//   1: P2PKH -> P_node (dust)
//   2: P2PKH -> Change
func BuildCreateRoot(params *CreateRootParams) (*MetanetTx, error)

// BuildCreateChild constructs a Metanet child node transaction.
// Template 2: Spends P_parent UTXO (Input 0), creating Metanet edge.
//
// Outputs:
//   0: OP_FALSE OP_RETURN <MetaFlag> <P_node> <TxID_parent> <Payload>
//   1: P2PKH -> P_node (dust)
//   2: P2PKH -> P_parent (dust, UTXO refresh)
//   3: P2PKH -> Change
func BuildCreateChild(params *CreateChildParams) (*MetanetTx, error)

// BuildSelfUpdate constructs a Metanet self-update transaction.
// Template 3: Spends own P_node UTXO, preserves ParentTxID.
//
// Outputs:
//   0: OP_FALSE OP_RETURN <MetaFlag> <P_node> <TxID_parent> <Payload>
//   1: P2PKH -> P_node (dust, refresh)
//   2: P2PKH -> Change
func BuildSelfUpdate(params *SelfUpdateParams) (*MetanetTx, error)

// BuildDataTransaction constructs an on-chain content data transaction.
// Template 4: OP_DROP content in spendable output locked to P_node.
//
// Outputs:
//   0: <content> OP_DROP OP_DUP OP_HASH160 <H160(P_node)> OP_EQUALVERIFY OP_CHECKSIG
//   1: P2PKH -> Change
func BuildDataTransaction(params *DataTxParams) (*MetanetTx, error)

// BuildOPReturn constructs the OP_RETURN script for a Metanet node.
//   OP_FALSE OP_RETURN <MetaFlag(4B)> <P_node(33B)> <TxID_parent(0|32B)> <Payload(var)>
func BuildOPReturn(pNode *ec.PublicKey, parentTxID []byte, payload []byte) (*script.Script, error)

// ParseOPReturn extracts Metanet fields from an OP_RETURN script.
// Returns (P_node, TxID_parent, payload_bytes, error).
func ParseOPReturn(s *script.Script) (*ec.PublicKey, []byte, []byte, error)

// EstimateFee estimates the transaction fee for a given transaction size and fee rate.
func EstimateFee(txSizeBytes int, feeRate uint64) uint64

// P2PKHScript creates a standard Pay-to-Public-Key-Hash locking script.
func P2PKHScript(pubKey *ec.PublicKey) (*script.Script, error)
```

## 数据结构

### OP_RETURN 布局
```
OP_FALSE OP_RETURN
  pushdata[0]: 0x6d657461           (4 bytes, "meta")
  pushdata[1]: <compressed_pubkey>  (33 bytes)
  pushdata[2]: <parent_txid>        (0 bytes for root, 32 bytes otherwise)
  pushdata[3]: <protobuf_payload>   (variable length)
```

### UTXO 自维持链
```
CreateChild:
  Input 0  = P_parent UTXO      (spent)
  Output 1 = P_child  UTXO      (new)
  Output 2 = P_parent UTXO      (refreshed, for next operation)

SelfUpdate:
  Input 0  = P_node UTXO        (spent)
  Output 1 = P_node UTXO        (refreshed)
```

## 错误处理

| 错误 | 条件 |
|------|------|
| `ErrNilParam` | 必需参数为 nil |
| `ErrInsufficientFunds` | 手续费 UTXO 不足以支付交易费 + 粉尘输出 |
| `ErrInvalidPayload` | 载荷（Payload）超过最大大小或为空 |
| `ErrInvalidParentTxID` | 父交易 TxID 不是 32 字节（非根节点时） |
| `ErrSigningFailed` | 交易签名失败 |
| `ErrScriptBuild` | 脚本构建失败 |

## 安全考量

1. **输入签名顺序**：Input 0 始终是 Metanet 相关的输入（P_parent 或 P_node）。Input 1 始终是手续费输入。此顺序对协议至关重要。

2. **粉尘限额执行**：所有 P_node/P_parent 的 P2PKH 输出必须恰好为 DustLimit（546 聪），以在保持可花费性的同时最小化成本。

3. **UTXO 追踪**：调用者必须追踪 BuildCreateChild 返回的 MetanetTx.ParentUTXO——这是对同一父目录后续操作所需的已刷新 P_parent UTXO。

4. **手续费估算**：手续费率应从网络查询。因手续费不足被拒绝的交易应以更高手续费率重建并重试（最多 3 次）。
