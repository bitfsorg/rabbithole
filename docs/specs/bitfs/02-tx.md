# 模块规范：libbitfs-go/tx

## 目的

用于 BitFS Metanet 操作的 BSV 交易构建模块。核心 API 是 `MutationBatch`——将多个节点操作（创建、更新、删除）打包进单笔交易。同时提供链上数据交易构建（DataTransaction）和 OP_RETURN 解析工具。

设计参考：ConceptDesign #8, #14, #24, #60; SystemDesign 第 4 节; DetailedDesign 第 4-B 节。

### 类型

```go
// UTXO represents an unspent transaction output tracked by the wallet.
type UTXO struct {
    TxID         []byte         `json:"txid"`          // 32 bytes
    Vout         uint32         `json:"vout"`
    Amount       uint64         `json:"amount"`        // satoshis
    ScriptPubKey []byte         `json:"script_pubkey"` // locking script bytes

}

// MetanetTx wraps a built BSV transaction with metadata about produced UTXOs.
type MetanetTx struct {
    RawTx      []byte // Serialized transaction bytes
    TxID       []byte // Transaction hash (32 bytes)
    NodeUTXO   *UTXO  // Output 1: P_node UTXO
    ParentUTXO *UTXO  // Output 2: P_parent refresh UTXO (nil for root/self-update)
    ChangeUTXO *UTXO  // Last output: change UTXO (nil if dust)
}

// DataTxParams holds parameters for building an on-chain data transaction.
type DataTxParams struct {
    NodePubKey  *ec.PublicKey  // For OP_DROP output locking
    NodePrivKey *ec.PrivateKey // D_node for signing
    Content     []byte         // Encrypted content to embed
    SourceUTXO  *UTXO          // UTXO to spend
    ChangeAddr  []byte         // 20-byte P2PKH hash for change

}
```

### MutationBatch API

MutationBatch 是构建 Metanet 交易的唯一路径。它将多个节点操作收集到单笔交易中，支持四种操作类型。

#### 操作类型

```go
type BatchOpType int

const (
    OpCreate     BatchOpType = iota // 创建子节点（OP_RETURN + P2PKH 刷新）
    OpUpdate                        // 更新现有节点（OP_RETURN + P2PKH 刷新）
    OpDelete                        // 删除节点（仅 OP_RETURN，无 P2PKH — UTXO 消亡）
    OpCreateRoot                    // 创建根节点（无输入 UTXO，OP_RETURN + P2PKH 刷新）
)
```

#### 批量操作类型

```go
// BatchNodeOp represents one node operation within a MutationBatch.
type BatchNodeOp struct {
    Type       BatchOpType
    PubKey     *ec.PublicKey  // Node's public key
    ParentTxID []byte         // Parent's TxID (for OP_RETURN field 2)
    Payload    []byte         // Serialized TLV payload
    InputUTXO  *UTXO          // UTXO to spend (nil for new creates — no existing UTXO)
    PrivateKey *ec.PrivateKey // Signing key for this node's input
}

// BatchResult holds the built transaction and per-op output mapping.
type BatchResult struct {
    RawTx      []byte            // Serialized unsigned TX
    TxID       []byte            // TX hash (computed after signing)
    NodeOps    []BatchNodeResult // One per op, in order
    ChangeUTXO *UTXO             // Change output (nil if dust)
}

// BatchNodeResult tracks the outputs for one operation.
type BatchNodeResult struct {
    OpReturnVout uint32 // Output index of the OP_RETURN
    NodeVout     uint32 // Output index of the P2PKH dust output
    NodeUTXO     *UTXO  // The produced P_node UTXO (nil for OpDelete)
}
```

### 节点身份与 Outpoint

多输出批量交易中，同一 TxID 包含多个节点。节点身份从 `(P_node, TxID)` 扩展为 `(P_node, TxID, Vout)`。`Node.Vout` 记录该节点 P2PKH 输出的索引（OpDelete 节点使用 OP_RETURN 位置，因为没有 P2PKH 输出）。

```go
// ParseTxToNodes parses all Metanet node operations from a transaction's
// outputs and returns fully populated Node objects with TxID and Vout set.
// For non-delete ops, Vout is the P2PKH output index.
// For delete ops, Vout is the OP_RETURN output index.
func ParseTxToNodes(outputs []TxOutput, txID []byte) ([]*metanet.Node, error)

// ParseNodeFromPushesWithOutpoint is like ParseNode but also sets TxID and Vout.
// Use this when parsing nodes from multi-output batch transactions.
func ParseNodeFromPushesWithOutpoint(pushes [][]byte, txID []byte, vout uint32) (*metanet.Node, error)
```

`OutpointStore` 是 `NodeStore` 的可选扩展接口，支持按 `(TxID, Vout)` 查找节点：


## 数据结构

### OP_RETURN 布局
```
OP_FALSE OP_RETURN
  pushdata[0]: 0x6d657461           (4 bytes, "meta")
  pushdata[1]: <compressed_pubkey>  (33 bytes)
  pushdata[2]: <parent_txid>        (0 bytes for root, 32 bytes otherwise)
  pushdata[3]: <tlv_payload>        (variable length)
```

### MutationBatch 输出布局

单笔交易包含多个节点操作时，输出按顺序排列：每个操作产生一对 OP_RETURN + P2PKH 输出（OpDelete 除外，仅 OP_RETURN），最后追加找零输出。

```
For each op (in order):
  [vout]   OP_FALSE OP_RETURN [MetaFlag, P_node, ParentTxID, Payload]   (0 sat)
  [vout+1] P2PKH -> P_node                                              (1 sat, OpDelete 时省略)

[last]   P2PKH -> ChangeAddr                                            (剩余找零)
```

**输入布局**：先是去重后的节点 UTXO 输入（具有 InputUTXO 的操作），再是手续费输入。相同 (TxID, Vout) 的节点输入只添加一次（自动去重）。

示例：一个包含 3 个操作（创建子节点 A、更新父节点、删除子节点 B）的批量交易：

```
Inputs:
  [0] P_parent UTXO (OpCreate A + OpUpdate parent 共用同一个父 UTXO，去重)
  [1] P_nodeB UTXO  (OpDelete B)
  [2] Fee UTXO

Outputs:
  [0] OP_RETURN (A: create child)
  [1] P2PKH -> P_A (1 sat)         ← NodeOps[0].NodeUTXO
  [2] OP_RETURN (parent: update)
  [3] P2PKH -> P_parent (1 sat)    ← NodeOps[1].NodeUTXO
  [4] OP_RETURN (B: delete)         ← NodeOps[2].NodeUTXO = nil
  [5] P2PKH -> Change
```

### UTXO 自维持链

MutationBatch 通过输出中的 P2PKH 刷新 UTXO 维持 Metanet DAG 的 UTXO 链：

```
OpCreate (创建子节点):
  Input:  P_parent UTXO (spent)
  Output: P_child P2PKH (new UTXO)
  → 父节点的 UTXO 需要通过同批次的 OpUpdate 或后续交易刷新

OpUpdate (自更新):
  Input:  P_node UTXO (spent)
  Output: P_node P2PKH (refreshed)
  → 同一节点的 UTXO 被刷新

OpDelete (删除):
  Input:  P_node UTXO (spent)
  Output: 无 P2PKH
  → 节点 UTXO 消亡，不可恢复

OpCreateRoot (创建根):
  Input:  无节点 UTXO
  Output: P_root P2PKH (new UTXO)
  → 仅消耗手续费输入
```

## 错误处理

| 错误 | 条件 |
|------|------|
| `ErrNilParam` | 必需参数为 nil |
| `ErrInsufficientFunds` | 手续费 UTXO 不足以支付交易费 + 粉尘输出 |
| `ErrInvalidPayload` | 载荷（Payload）为空或批量操作为空 |
| `ErrInvalidParentTxID` | 父交易 TxID 不是 0 或 32 字节 |
| `ErrSigningFailed` | 交易签名失败（RawTx 为空、UTXO 数量不匹配、PrivateKey 缺失等） |
| `ErrScriptBuild` | 脚本构建失败 |
| `ErrInvalidOPReturn` | OP_RETURN 脚本格式错误（push data 不足、字段长度错误等） |
| `ErrNotMetanetTx` | 交易不是有效的 Metanet 交易（缺少 MetaFlag） |

## 安全考量

1. **输入排序**：MutationBatch.Build() 中，节点 UTXO 输入在前（按操作顺序、去重后），手续费输入在后。MutationBatch.Sign() 按相同顺序重建签名 UTXO 数组。

2. **输入去重**：同一 (TxID, Vout) 的节点输入只添加一次。例如，对同一父目录的多个子操作（创建子节点 + 父节点自更新）共享一个输入。

3. **粉尘限额执行**：所有 P_node P2PKH 输出恰好为 DustLimit（1 聪），在保持可花费性的同时最小化成本。BSV 已移除 dust limit。

4. **OpDelete 无刷新**：OpDelete 类型的操作不产生 P2PKH 输出，节点 UTXO 永久消亡。BatchNodeResult.NodeUTXO 为 nil。

5. **签名流程分离**：Build() 返回未签名交易，Sign() 单独签名。这允许在签名前检查交易结构。签名后 BatchResult.TxID 和所有 NodeUTXO.TxID 被更新。

6. **手续费估算**：EstimateTxSize 根据输入数、输出数、载荷大小估算交易字节数。EstimateFee 按 ceil(size * rate / 1000) 计算费用。
