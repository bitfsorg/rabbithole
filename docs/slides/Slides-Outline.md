## 一、视觉识别 (VI)

### 风格定位：Dark Botanical

温暖、有机、精致的暗色调设计，以古典衬线体为标题，传递"扎根于坚实技术的自然生长"的品牌气质。

### 色彩系统

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `--bg` | `#0f0f0f` | 全局背景，近纯黑 |
| `--text-primary` | `#e8e4df` | 正文主色，暖白 |
| `--text-secondary` | `#9a9590` | 辅助文字，暖灰 |
| `--accent-warm` | `#d4a574` | 主强调色，铜金色（标题下划线、箭头、高亮） |
| `--accent-pink` | `#e8b4b8` | 辅助强调色，玫瑰粉（"致命缺陷"、否定信息） |
| `--accent-gold` | `#c9b896` | 第三强调色，香槟金（引用、金句、第三状态） |

### 字体

| 角色 | 字体 | 权重 | 说明 |
|------|------|------|------|
| 展示字体 | Cormorant (serif) | 400/500/600, italic | 标题、数字、大字。古典衬线，贵族气质 |
| 正文字体 | IBM Plex Sans | 300/400/500 | 正文、标签、描述。现代清晰，工程气质 |

**Google Fonts 加载**：
```
Cormorant:ital,wght@0,400;0,500;0,600;1,400;1,500
IBM+Plex+Sans:wght@300;400;500
```

### 视觉元素

- **渐变光球 (Orb)**：每页放置 1-3 个大型模糊圆形渐变球（warm/pink/gold），`filter: blur(80px); opacity: 0.08~0.18`，制造幽微的光晕氛围
- **竖线 (VLine)**：1px 宽的 accent-warm 竖线，上下渐隐，`opacity: 0.2`，增加纵深层次
- **噪点纹理**：`body::after` 叠加 SVG fractalNoise，`opacity: 0.5`，消除数字感
- **进度条**：顶部 2px 渐变条（warm → pink → gold），随滚动推进
- **导航圆点**：右侧 6px 圆点列，当前页高亮为 accent-warm

### 自适应策略

- **根字号缩放**：`html { font-size: clamp(14px, 0.833vw, 32px); }` — 以 1920px 为基准 (16px)，4K 下自动放大至 32px
- **所有 `max-width` 使用 `vw` 单位**，不使用固定 `px`
- **所有 `font-size` 使用 `clamp(min_rem, preferred_vw, max_rem)`** 三段式
- **水平 padding**：`max(40px, 5vw)`，无上限
- **竖向 padding**：`clamp(40px, 6vh, 80px)`
- **高度断点**：`@media (max-height: 700px)` 缩小字号适配矮屏
- **窄屏断点**：`@media (max-width: 600px)` 隐藏导航点、列转为垂直堆叠

### 动画

- **Reveal**：每个 `.reveal` 子元素初始 `opacity:0; translateY(20px)`，slide 可见时以 0.1s 间隔依次浮入
- **Stagger**：容器内子元素以 0.15s 间隔依次 fadeUp
- **滚动锁定**：`scroll-snap-type: y mandatory` + `scroll-snap-align: start`
- **尊重用户偏好**：`prefers-reduced-motion: reduce` 时禁用所有动画

## 三、技术规格

### 页面结构

- 单文件 HTML（无外部依赖，仅引用 Google Fonts CDN）
- 25 个 `<div class="slide">` 全屏区块，CSS scroll-snap 纵向滚动
- 每页通过 `data-part` 属性标记所属章节（1-7）
- IntersectionObserver 驱动 `.visible` 类切换，触发 reveal 动画
- 导航圆点（nav-dots）和进度条（progress-bar）由 JS 动态生成

### CSS 组件清单

| 组件类 | 用途 | 典型页面 |
|--------|------|----------|
| `.columns > .col` | 三列等宽卡片 | Frame 2, 3, 8, 9 |
| `.flow-row > .flow-step + .flow-arrow` | 横向流程（步骤 + 箭头）| Frame 4, 7 |
| `.split > .split-half` | 左右分屏 | Frame 5, 13, 15, 23 |
| `.iceberg > .iceberg-above + .iceberg-below` | 冰山模型 | Frame 11 |
| `.layer-stack > .layer` | 垂直层次堆叠 | Frame 12 |
| `.card-grid > .card` | 自适应网格卡片 | Frame 16, 18, 20, 24 |
| `.num-flow > .num-step` | 编号步骤卡片 | Frame 14 |
| `.cdn-flow > .cdn-node + .flow-arrow` | CDN 流程节点 | Frame 10, 19 |
| `.compare-block > .compare-row` | 新旧对比行 | Frame 17 |
| `.ball-room + .ball` | 椭圆曲线弹球演示 | Frame 6 |
| `.insight-box` | 金句/结论高亮框 | 多处 |

| `.final-lines > .final-line` | 结尾递进金句 | Frame 25 |
