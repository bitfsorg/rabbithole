# 演示文稿 (Slides)

BitFS 项目演示文稿。

## 文件结构

```
slides/
├── Slides-Outline.md              ← 内容大纲 (源文件)
└── BitFS-presentation.html        ← 生成的 HTML 幻灯片
```

## 工作流

**Slides-Outline.md 是唯一的源文件。**

大纲中定义了：视觉风格 (Dark Botanical)、色彩系统、每页幻灯片的内容要点。
修改大纲后重新生成 `BitFS-presentation.html`。

## 设计风格

- Dark Botanical：暗色背景 + 铜金色强调
- 古典衬线标题字体
- 纯 HTML + CSS 实现（浏览器中打开即用）
